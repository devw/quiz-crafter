# 🧠 Quiz Crafter

**quiz-crafter** — a lightweight CLI tool that automatically creates **Google Forms quizzes** from a JSON definition file.

---

## 🎯 Purpose
Easily generate Google Forms from structured quiz data.  
Ideal for teachers, researchers, or developers who need to create quizzes **programmatically**.

---

## 🚀 Quickstart (Developer Setup)

### ⚙️ Prerequisites
- 🟩 **Node.js ≥ v22**
- 🧶 **Yarn**
- ☁️ **Google Cloud Project** with:
  - ✅ **Google Forms API** enabled  
  - ✅ **Google Drive API** enabled  
- 🔐 A **Service Account JSON key** downloaded from Google Cloud
